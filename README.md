# 简历投递与进度管理助手

一个不依赖构建工具的 Chrome Manifest V3 扩展。它把求职过程中最容易分散的两件事放到了一起：在招聘页面快速调用自己的简历资料，以及记录每一份岗位后续走到哪一步。

当前版本：`2.2.2`

## 它解决什么问题

- 简历资料不用反复打开、复制、粘贴。先把常用信息维护在资料库，填写网页时聚焦输入框，再从侧栏选择要插入的字段。
- 投递完成后不用另外开表格记公司、岗位和状态。侧栏可以读取当前职位页面，填入收录表单，确认后保存到本地看板。
- 岗位页面结构差异很大。插件先使用页面结构化数据和本地规则；如果配置了 LLM，还可以把 JD 交给模型提取岗位信息和 JD 内容。

## 使用流程

### 第一次使用

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录，也就是包含 `manifest.json` 的目录。
5. 点击插件图标，先进入“我的简历资料库”，填写个人信息。

### 填写招聘表单

1. 打开招聘网站的申请页面。
2. 点击右侧“投递助手”胶囊，或者按 `Ctrl+Shift+F` 打开侧栏。
3. 将光标放进目标输入框。
4. 点击侧栏中的简历字段，内容会插入当前光标位置；网页框架没有正常接收时，会同时复制到剪贴板。

### 收录岗位

1. 在职位详情页打开“投递助手”。
2. 点击“一键收录当前岗位”。
3. 核对公司、岗位、城市、阶段和日期。
4. 如果启用了 AI，职位描述和职位要求也会一并填入；确认无误后点击“确认存入看板”。

自动识别只是预填，不是最终确认。招聘网站的标题、页面状态和公司信息可能不完整，保存前建议检查一次。

## AI 岗位解析

在看板的“AI 解析配置”中填写一个 OpenAI 兼容接口：

- `Base URL`：服务商提供的兼容接口地址，例如 `https://api.deepseek.com/v1`
- `API Key`：对应服务商的密钥
- `模型名`：例如 `deepseek-chat` 或其他可用模型
- “启用 AI 解析”：开启后，点击“一键收录”才会调用模型
- “关闭思考模式”：对 DashScope / Qwen3 等支持该参数的模型默认关闭，以减少等待时间

一次解析请求会让模型返回结构化 JSON，字段包括公司、岗位、城市、阶段、投递日期、职位描述和职位要求。公司名也可以结合页面标题和 URL 域名识别，例如 `campus.dewu.com` 可还原为“得物”。

LLM 调用失败时会回退到本地规则识别。AI 配置页底部的“LLM 调用日志”可以查看 API 耗时、请求次数、HTTP 状态和输入输出长度，日志不会保存 API Key、JD 原文或完整模型响应。

启用 AI 后，岗位页面文字会发送给你填写的模型服务商。简历资料和投递记录仍保存在浏览器本地，但不应把个人隐私粘贴到发送给模型的页面内容中。

## 界面入口

- **浏览器插件图标**：打开快捷面板，可查看投递统计并进入看板、简历资料库或数据备份。
- **网页悬浮胶囊**：打开网页侧栏。可以在快捷面板中关闭它，关闭后 `Ctrl+Shift+F` 仍然可用。
- **胶囊自由拖拽**：在快捷面板中开启后，可将胶囊拖到页面任意位置；靠近左右边缘会自动吸附，位置会跨页面记忆。
- **侧栏标题栏**：侧栏打开后，按住顶部标题栏可以移动整个侧栏窗口；靠近左右边缘时会吸附。

## 数据与权限

- 简历资料、投递记录和设置使用 `chrome.storage.local` 保存。
- 历史备份快照使用浏览器 IndexedDB 保存。
- OCR 识别资源随扩展内置，截图识别可以离线完成。
- AI 解析是例外：只有在配置并启用后，岗位页面文字才会发送到外部模型接口。
- 扩展通过 Manifest V3 的 content script 运行在 HTTP(S) 网页中；Chrome 内置页面、扩展商店等受限制页面不支持注入。

## 当前限制

- 不同招聘网站的 DOM 结构差异很大，本地规则不可能覆盖所有页面。
- AI 解析结果仍需人工核对，尤其是公司名、招聘阶段和日期。
- API 的响应速度、费用和可用性由所配置的模型服务商决定。
- 网页表单的最终校验和提交仍由用户完成，插件不会替用户提交申请。

## 项目结构

```text
manifest.json       扩展配置与权限
background.js       Service Worker、存储消息和 LLM 请求
content.js          网页侧栏、简历字段插入和岗位收录
popup.html/js/css   浏览器工具栏快捷面板
dashboard.html/js   投递看板、简历资料库、备份和 AI 配置
dashboard.css       看板样式
ocr/                离线 Tesseract 资源
tests/              Node.js 测试
```

## 本地检查

项目没有 npm 构建步骤。修改脚本后可以运行：

```bash
node --check background.js
node --check content.js
node --check dashboard.js
node --check popup.js
node --test tests/*.test.cjs
```
